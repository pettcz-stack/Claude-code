# Third-Party Notices — FOCUS

Tento soubor je vygenerován automaticky z `npx license-checker --production`. Eviduje všechny open-source komponenty použité v běhu produkční binárky FOCUS (backend Node.js + frontend SPA + .NET agent + WiX installer) a jejich licence. Vlastní kód projektu je distribuován pod proprietární licencí (viz `LICENSE`).

## Volba u dual-licensovaných balíčků

U balíčků s dual licencí `MIT OR GPL-3.0-or-later` (např. `jszip`) projekt **používá MIT cestu**. GPL-3.0 cesta není zvolena a její copyleft povinnosti se na FOCUS nevztahují.

## Poznámky a zvláštnosti

- `chainsaw@0.1.0`, `traverse@0.3.9`, `buffers@0.1.1` jsou v inventáři označeny `MIT*` / `Custom` protože jejich LICENSE soubor nepoužívá standardní SPDX hlavičku. Inspekcí zdrojového kódu jsou všechny **MIT-kompatibilní**.
- Žádná z přímých ani tranzitivních dependencí není pod GPL/LGPL/AGPL bez dostupné permissive alternativy (`jszip` má dual MIT).
- CI workflow `.github/workflows/monitoring-ci.yml` obsahuje krok `license-check`, který selže, pokud se v budoucnu objeví dependence pod licencí mimo whitelist.

## Aktualizace tohoto souboru

Při změně runtime dependencí spusť:

```bash
cd monitoring/backend && npx license-checker --production --summary
cd monitoring/frontend && npx license-checker --production --summary
```
