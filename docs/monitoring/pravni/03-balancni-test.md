# Balanční test oprávněného zájmu

*(Vzor k čl. 6 odst. 1 písm. f) GDPR – posuďte s DPO/právníkem. Viz `00-DISCLAIMER.md`.)*

**Správce:** [DOPLŇTE]  **Zpracování:** Monitoring využití firemních zařízení (WorkView)
**Datum:** [DOPLŇTE]

## 1. Test účelu – existuje oprávněný zájem?

Oprávněný zájem: kontrola přiměřeného využití pracovní doby a svěřených
pracovních prostředků, ochrana majetku a organizace práce. Opora v § 316
odst. 1 zákoníku práce. **Závěr: ano.**

## 2. Test nezbytnosti – je zpracování nezbytné?

- Zájem nelze rozumně naplnit bez přehledu o využití zařízení.
- Zpracování je **minimalizováno**: jen agregované metriky, žádný obsah.
- Méně invazivní prostředky (namátková kontrola) neposkytují srovnatelný,
  objektivní a nepřetržitý přehled bez vyšší zátěže.
**Závěr: nezbytné v daném (omezeném) rozsahu.**

## 3. Test proporcionality – převažuje zájem správce nad právy subjektu?

| Faktor | Hodnocení |
|---|---|
| Povaha údajů | Provozní metriky aktivity, **nikoli** obsah; bez zvláštních kategorií |
| Rozumné očekávání zaměstnance | Jde o **služební** zařízení; zaměstnanec je **předem informován** |
| Dopad na soukromí | Nízký–střední; vyloučen obsah, screenshoty, soukromá data |
| Záruky | Transparentnost, řízení přístupu, audit log, retence, šifrování |
| Automatizované rozhodování | Neprobíhá; data jsou podpůrná, ne výhradní podklad sankcí |

**Předběžný závěr:** při dodržení záruk oprávněný zájem **převažuje**.
Zpracování se nesmí dotýkat soukromé komunikace a musí respektovat § 316/2 ZP.

## 4. Záruky a podmínky (závazné)

1. Žádný sběr obsahu (kláves, obrazovky, e-mailů, mikrofonu, kamery).
2. Předchozí prokazatelné informování zaměstnanců + viditelná indikace agenta.
3. Přístup jen pověřeným osobám, vše logováno.
4. Dodržení retenčních lhůt a automatické mazání.
5. Respektování **námitky** zaměstnance a posouzení v konkrétním případě.
